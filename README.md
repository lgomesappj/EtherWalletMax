# EtherWalletMax

EtherWalletMax is a high-performance, blockchain-based cryptocurrency manager featuring real-time transaction processing and automated wallet synchronization capabilities.

EtherWalletMax is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/EtherWalletMax.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure EtherWalletMax, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
